# GEAYI Nativo (Unity)

Proyecto Unity del juego GEAYI: Obby Xtreme 3D para Android.

## Cómo abrir
1. Instala Unity Hub y Unity 2022 LTS o más nuevo.
2. En Unity Hub: Add project → selecciona esta carpeta.
3. Abre el proyecto. Los scripts están en Assets/Scripts.

## Estructura
- Assets/Scripts/Core — GameManager, SaveSystem
- Assets/Scripts/Player — PlayerController, CameraFollow
- Assets/Scripts/World — CityBuilder, StreamingManager
- Assets/Scripts/UI — MainMenu, HUD
- Assets/Scripts/Vehicles — VehicleController
- Assets/Scripts/BuildMode — BuildManager
- Assets/Scripts/Multiplayer — NetworkSetup (base)
- docs/PLAN.md — plan de fases
